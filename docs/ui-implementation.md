# UI Implementation
Files: Sources/Orbit/Theme.swift (tokens: T palette, Panel, SectionTitle, RingGauge, MeterBar, Sparkline, StatusChip, EmptyState, TreemapStrip, button styles, healthStatus), App.swift (selection-based shell with grouped custom sidebar + Dashboard), Views.swift (Cleanup, Disk, Apps, Maintenance, Processes, History, Settings — same view models and OrbitCore calls as before, restyled).
Decisions: dark-only; lime accent, cyan only for disk/memory info; flat colour, tone-step surfaces, no gradients/shadows; orbit ring brand mark reused as CPU gauge; sparkline = real samples collected every 2s since launch (max 45), labeled as such; health thresholds documented in design-system.md; disk treemap = top 11 entries + aggregated Other, list stays lazy; app icons via NSWorkspace; loading empty-states added for Disk/Apps/Processes after screenshot review found blank screens during scans.
